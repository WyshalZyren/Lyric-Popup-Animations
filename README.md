# Lyric Popup Animations

A collection of Python projects that display animated lyric popups synchronized with music.

Each song has its own folder with custom timing, popup positions, color effects, and animations.

## Current Projects

### Wish You Were Here

A lyric popup animation project based on **"Wish You Were Here" by Avril Lavigne**.

Features include:

* Timed lyric popups
* Animated window opening
* Fixed popup positions
* Alternating black and white backgrounds
* Alternating text colors
* Music synchronization
* Smooth closing animations

## Requirements

Make sure you have:

* Python 3
* pygame

Install pygame using:

py -m pip install pygame

## How to Run

1. Open the folder of the song you want to run.

2. Add your own audio file inside that folder.

3. Rename the audio file to:

song.mp3


4. Open a terminal inside the song folder.

5. Run:

py main.py

The music and lyric animations should start automatically.

Each project may use different:

* lyric timings
* popup positions
* animation styles
* color effects
* sliding effects

## Notes

The music files are not included in this repository.

You will need to provide your own legally obtained audio file and rename it to `song.mp3` before running a project.
